# Corresponding source

For a `pyyggdrasil` wheel, download
`pyyggdrasil-<VERSION>-corresponding-source.tar.gz` from the matching
[`v<VERSION>` GitHub release](https://github.com/planning-and-learning/yggdrasil/releases).
It contains Yggdrasil's source, build scripts, and patches together with the
exact upstream native dependency sources, including required Git submodules.
The matching Yggdrasil-only source distribution is also available from the
[PyPI files page](https://pypi.org/project/pyyggdrasil/#files).

[`SOURCES.json`](SOURCES.json) is the canonical, machine-readable manifest of
the repositories, revisions, archive URLs, and checksums used to build those
dependencies.
